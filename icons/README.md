# Extension Icons

This directory should contain the following icon files for your Chrome extension:

## Required Icons

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Specifications

- **Format**: PNG with transparency
- **Style**: Should match your extension's theme
- **Design**: Simple, recognizable, and professional
- **Colors**: Consider both light and dark themes

## Creating Icons

You can create these icons using:
- **Online Tools**: Canva, Figma, or similar design tools
- **Icon Generators**: favicon.io, realfavicongenerator.net
- **Design Software**: Adobe Illustrator, Sketch, or GIMP

## Icon Guidelines

- Keep designs simple and scalable
- Ensure good contrast for visibility
- Test how they look in different contexts
- Consider creating a simple "AI" or "writing" themed icon

## Temporary Solution

For development and testing, you can:
1. Use placeholder images from any icon library
2. Create simple colored squares with text
3. Download free icons from sites like flaticon.com or icons8.com

## Example Icon Ideas

- **AI Brain**: Representing AI-powered suggestions
- **Pen/Pencil**: Symbolizing writing assistance
- **Lightbulb**: Indicating smart suggestions
- **Text Bubble**: Showing autocomplete functionality

Remember to replace these placeholder icons before publishing to the Chrome Web Store!
